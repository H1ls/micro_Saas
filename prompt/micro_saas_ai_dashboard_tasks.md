# Микро-SaaS AI-дашборд - чеклист задач

## Цель MVP

Собрать микро-SaaS, который принимает сырые данные в виде CSV/Excel-файла или неструктурированного текста, анализирует их с помощью LLM и превращает в понятный AI-дашборд с нарративом, графиками и чатом по данным.

> Принцип MVP: сначала рабочий end-to-end сценарий, затем визуальная полировка. Не добавлять авторизацию, сложный RAG и лишнюю инфраструктуру.
